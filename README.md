📸 Attendance Face Recognition System (Google Apps Script)
ระบบบันทึกเวลาเข้างานด้วยการสแกนใบหน้า โดยใช้ face-api.js ทำงานร่วมกับ Google Apps Script และบันทึกข้อมูลลงใน Google Sheets โดยตรง ไม่ต้องมี Server แยก

✨ คุณสมบัติ
Face Detection & Recognition: ตรวจจับและจดจำใบหน้าผ่านเบราว์เซอร์โดยใช้ AI (face-api.js)

No Server Required: ทำงานบน Google Apps Script ฟรี 100%

Easy Data Management: จัดเก็บข้อมูลพนักงานและประวัติการเข้างานใน Google Sheets

Responsive Design: รองรับการใช้งานผ่านหน้าจอคอมพิวเตอร์และมือถือ

🛠 ส่วนประกอบของระบบ
code.gs: ส่วนควบคุมการทำงานฝั่ง Server (Google Apps Script)

menu.html: หน้าแรกสำหรับเลือกเมนูลงทะเบียนหรือสแกนเข้างาน

register.html: หน้าสำหรับลงทะเบียนใบหน้าพนักงานใหม่

scan.html: หน้าสำหรับสแกนใบหน้าเพื่อยืนยันตัวตนและบันทึกเวลา

📋 วิธีการติดตั้ง (Setup)
สร้าง Google Sheets:

สร้าง Sheet ชื่อว่า Users เพื่อเก็บข้อมูลชื่อและ Profile ใบหน้า

สร้าง Sheet ชื่อว่า Attendance เพื่อเก็บประวัติการเข้างาน

ตั้งค่า Google Apps Script:

ไปที่เมนู Extensions > Apps Script

คัดลอก Code จากไฟล์ code.gs, menu.html, register.html, และ scan.html ไปวางในโปรเจกต์

Deployment:

กดปุ่ม Deploy > New Deployment

เลือกประเภทเป็น Web App

ตั้งค่า "Who has access" เป็น Anyone (เพื่อให้พนักงานเข้าถึงหน้าสแกนได้)

Copy URL ที่ได้ไปใช้งาน

🚀 วิธีการใช้งาน
การลงทะเบียน (Register):

ไปที่หน้า "ลงทะเบียนพนักงานใหม่"

พิมพ์ชื่อพนักงาน และกดบันทึกใบหน้า (แนะนำให้บันทึก 3 มุม: หน้าตรง, หันซ้าย, หันขวา เพื่อความแม่นยำ)

การสแกนเข้างาน (Scan):

ไปที่หน้า "สแกนเข้างาน"

มองกล้องเพื่อให้ระบบวิเคราะห์ใบหน้า

เมื่อระบบพบข้อมูล ให้กด "ใช่" เพื่อยืนยันตัวตนและบันทึกเวลาลง Google Sheets

⚙️ การตั้งค่าเพิ่มเติม
ในไฟล์ scan.html คุณสามารถปรับค่า MATCH_THRESHOLD เพื่อกำหนดความเข้มงวดในการตรวจจับได้:

ค่า น้อย (เช่น 0.40): มีความแม่นยำสูงมาก (โกงยาก) แต่อาจสแกนติดยากขึ้น

ค่า มาก (เช่น 0.60): สแกนติดง่าย แต่อาจเกิดการจำผิดคนได้
